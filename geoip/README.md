Place `GeoLite2-City.mmdb` here.

Download it (free) via:
1. https://www.maxmind.com/en/geolite2/signup -- create an account
2. Under "Manage License Keys", generate a license key
3. https://www.maxmind.com/en/accounts/current/geoip/downloads -- download
   "GeoLite2 City" in MMDB format
4. Extract the .mmdb file into this folder

Not required on Windows/macOS if OS-native location services are available
and permitted -- this is only the fallback path (and Linux's only path).
